慢慢改，也认真留痕。

这里记录小站公开内容与阅读体验的变化。每次整理，留下一条能回头找到的记录。

  1. 2026-10-18版本 2026.10.18.3

    让小字更易读，让手机导航舒展开

    • 改进

      保留柔粉配色与版式层级，提高公开页面正文、说明和标签字号。

    • 改进

      手机主导航改为三列两行，较窄屏幕的入口卡片与排查步骤自然换行，文章表格保留列宽并支持横向滑动。

    • 修复

      浏览器禁用存储时，本次手动选择的主题仍能在返回页面和系统主题变化后保持。

    • 完善

      文章补充分享配图，WebP 图片使用对应的资源类型。

  2. 2026-10-18版本 2026.10.18.2

    补齐分享信息，让首页跟上内容

    • 新增

      公开页面补齐规范链接与分享卡片信息（Open Graph / Twitter），分享链接时能显示标题、简介与配图。

    • 改进

      首次访问且未手动切换主题时，跟随系统的明暗偏好；手动选择后仍记住选择。

    • 修复

      栏目根路径（/notes/、/frameworks/、/projects/）补充跳转页，直接访问不再落空。

    • 改进

      首页「最近整理」的阅读时长改为按正文实际字数估算，修改日志卡片自动取最新一条记录。

    • 优化

      首页插画改用 WebP 多尺寸加载，首屏图片体积从约 415 KB 降到 16–39 KB。

    • 新增

      robots.txt 标注站点地图地址，便于搜索引擎发现全部公开页面。

  3. 2026-10-18版本 2026.10.18

    让记录有时间，也有来路

    • 发布

      公开主页迁移至 moyuspace7.github.io，公开成品通过 GitHub 提交与自动发布保留版本记录。

    • 新增

      修电脑日期档案：按实际事件日期记录问题、证据、操作与阶段结果。

    • 新增

      可手动播放的排查过程示意与本地时间小卡，减少动态效果时保持静态。

    • 新增

      公开修改日志，保留每轮整理的日期、变化和已知限制。

    • 整理

      为既有维修主题补充逐日条目，明确区分故障发生时间与文章整理时间。

  4. 2026-10-17版本 2026.10.17

    统一阅读体验，补上第一批内容

    • 修复

      首页与文章共用明暗主题设置，往返页面时保留选择。

    • 改进

      统一文章标题与正文字体，为目录定位加入平滑滚动。

    • 整理

      减少重复的关于入口，加入维修总览、蓝屏分析、网络恢复与记录模板。

    • 设计

      采用奶白、柔粉、莓红与少量暖金，保留轻松的插画氛围。

记录是怎样维护的

每轮改动分别保留“改了什么”的文字记录和可比较的工程版本。需要恢复时，由维护者选择历史版本、检查差异，再重新构建与发布。

这里展示的是公开更新摘要。它不提供访客回退按钮，也不等同于每个文件的完整差异；发布日期与文章里记载的事件日期会分别标注。
